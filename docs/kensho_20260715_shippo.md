# 検証報告 2026-07-15: 「安い三連複しか当たらない」問題の解剖と打ち手の採否

> 検証環境: V11.2.0（§5修正込み）、リプレイ882R（5/17〜7/14、スプシ係数サマリー由来）＋基準718R。
> 実験スクリプト: replay/experiment_tail.mjs（追加候補買い目の単独精算器）。
> 本報告の数字はすべて再現可能（fixtures_0705_0714.json / スプシCSV再抽出）。

## 1. 主訴の裏付け（事実）

- 的中314R中94R（30%）が「荒天3連複のみ」的中、うち75Rは配当1000円未満。
- 晴天3連複の的中配当は中央値290円、荒天3連複530円。1R=10点1000円投入なので**当たっても中央値では赤字**。
  「的中したのに収支マイナス」が的中レースの54%。
- 収益源は晴天3連単の稀な爆発のみ（晴天3連単単独: 回収90.2%だが上位5本除外で48.4%）。
  月次回収の差（5月99.9%→7月64.6%）は払戻上位5本でほぼ説明され、トリム後は各月41〜55%に収斂。
  **回収率の見かけの好不調はほぼ大穴の分散**。

## 2. 尻尾（万車券）の正体 — 点数追加では獲れない

万車券レース252R（全体の29%）で買い目候補（平均4.0人）から漏れた入着選手281人のプロファイル:
- 競走得点順位 6〜7位が47%、脚質「追」69%、W印「無」67%。入着位置は1/2/3着ほぼ均等。
- スコアベースのモデルが構造的に最下位に置く選手であり、**1〜2点の追加で拾える形をしていない**。

## 3. 条件帯エッジは存在しない（ケン判断材料としての注意）

レース前観測可能な条件（風・級班・指数・場・組合せ）で回収率を切ると、
半期分割で**すべての「良い帯」が反転する**（girls×指数0: 前半242.9%→後半75.9% 等）。
条件帯の好成績は大穴ノイズ。**「この条件なら買い」という安定帯は現行エンジンには無い**。
指数別実績の併記表示（§9最終形）を実装する場合も、回収率でなく的中率・配当帯を出すべき。

## 4. 係数機構の正体 — 「順位当て」ではなく「配当加重の歪み取り」

素の競走得点順（係数なし）で同じ買い目構造を組んだ場合との比較（晴天令500円/R、882R）:

| | 3連複セット的中率 | 回収率 | 前半/後半回収 |
|---|---|---|---|
| エンジン（全係数） | 12.5% | 89.0% | **132.9% / 45.1%** |
| 素の得点順 | 15.4% | 46.6% | 46.5% / 46.6% |

- **エンジンは「誰が来るか」では素の得点順に一度も勝っていない**（1着捕捉率も常時6〜13pt負け）。
- 勝っているのは配当込みの期待値であり、その優位は5/17〜6/20に集中（旬別+39〜+102pt）、
  6月下旬以降は消失〜逆転（7月中旬: 3連複セット的中1/59、二項検定でノイズ棄却）。
- 直近の外し方の型: **ほぼ無風のレースでライン系係数が本命1人を外へ押し出し、素の得点順なら当たっていた**（7月中旬で9R確認）。

## 5. 発見された改修候補: 強風域の風補正過剰（未採用・OOS待ち）

風4m+（実効）でエンジンは素の得点順に両指標で負ける（回収44.0% vs 62.9%、セット的中11.2% vs 15.2%）。
実効風速4m以上で風補正を減衰させる実験エンジン（replay/engines/experiment_windcap_v1.js、damp=0.3）:

| | 718R回収 | トリム5 | 前半/後半 | 級別 |
|---|---|---|---|---|
| V11.2.0+§5（基準） | 87.2% | 63.9% | 90.1/83.7% | — |
| windcap damp0.3 | **89.5%** | **66.3%** | 90.7/88.4% | a-kyu+3.7 s-kyu+4.9 girls±0 a-chal-1.0 |

感度: damp 0.0/0.3/0.5/0.7 いずれも基準に勝ち（ノブの崖ではない）。減衰が強いほど良い傾向
＝**4m超では現行の風向ベクトル押しが逆効果**の示唆。
**未採用の理由**: 選定を718R（同じ測定基準）で行ったため過適合リスクがある。OOS期間（7/5〜14）は
強風レースが無く検証不能だった。**風のある新規レースが溜まってから OOS で追試し、勝てば採用**。

## 6. 総括 — どうしたらいいのか

（※ 本節の先に、§7「八ヶ月の成果の評価」を必ず読むこと。「構造的に困難」の意味を
誤読すると、このプロジェクトの資産を捨てる判断につながる）

1. **買い目の追加・組替えで回収率は直らない**（§10/§11系は全滅。候補の形が数学的に尻尾と噛み合わない）。
2. **回収率の月次変動は大穴の分散**。一喜一憂の対象ではない（トリム回収率を常設したのはこのため）。
3. 実力の問題は2つに絞られた:
   - (a) 強風域の風補正が逆効果（→ §5の候補、OOS追試待ち）
   - (b) 無風域でライン系係数が本命を外す → **検証済み・棄却**（2026-07-15）。
     風<1.5mで c_l を半減: 718R 87.2→87.0%・OOS 60.8→60.6%（微減）。全カット: 76.3%（大敗）。
     7月中旬の外し方の型は実在するが、c_l は無風域でも総体ではプラス。触らないこと。
4. 期待値ベット（オッズ取得）なしで恒常的な100%超えは構造的に困難。スプシにオッズ列を
   追加する入力改修が、係数いじりより先の根本打ち手である可能性が高い。

## 7. 八ヶ月の成果の評価 —「何にもならなかった」への反論【2026-07-15 開発者との対話より】

本検証の結論「係数の工夫だけでは控除率25%の壁を恒常的に超えるのは構造的に困難」を受けて、
開発者から「八ヶ月、何にもならなかった」との言葉があった。以下はそれへの反論であり、
将来のセッションがこのプロジェクトの価値を誤認しないための記録である。

### 7-1. 本検証自体が八ヶ月の産物の上に成立した

「構造的に困難」という結論に数時間で到達できたのは、八ヶ月かけて作られた計測系
——リプレイ台、実払戻つき測定基準、全レースのスナップショットが残るログ基盤、
fixtures変更禁止の規律——の上に乗ったからである。この計測文化がなければ今日の結論は
出せず、さらに数ヶ月、係数調整で彷徨っていた。個人開発の予想ツールでこの水準の
計測系を持つものは例外的である。

### 7-2. 「構造的に困難」の正確な意味

困難なのは**「係数の工夫だけでは」**恒常的に100%を超えること、である。
エンジンが無力という意味ではない:

- 素の競走得点順（市場コンセンサス相当）は回収46%しか返さない世界で、
  本エンジンは実在する優位（旬別+39〜+102pt、5/17〜6/20）を叩き出していた。
- 優位が「一度でも実在した」こと自体、大半の予想ロジックが到達しない場所である。
- 未解決なのは優位の**源泉の特定**（現状の仮説.md C4）であり、優位の不在ではない。

### 7-3. 「死んだ仮説の一覧」は発見と同価値

本日確定した9つの死んだ仮説（現状の仮説.md B1〜B9）は、計測で潰された道の記録である。
ギャンブルのモデル開発において、大半の開発者は B3（条件で絞れば勝てる）や
B8（あの頃は良かった）の周りを何年も回り続ける。このプロジェクトはもうそこに戻らなくてよい。
これは八ヶ月の計測文化だけが生み出せた種類の資産である。

### 7-4. 最も太い道が手つかずで残っている

現行エンジンは「誰が来そうか」を計算するが、「その目にいくら付いているか」（オッズ）を
一度も見たことがない。顔ぶれを半分捕捉しながら赤字なのは、値札を見ずに買い物をしている
からであり、予想力の敗北ではない。オッズ列の追加（現状の仮説.md C2）は係数改修より
地味だが、八ヶ月で初めて見つかった「壁の向こう側に通じている可能性のある扉」である。

### 7-5. 結語

八ヶ月かけて分かったのは「この山は登れない」ではなく、**「ルートは一本に絞られた」**である。
ロジックのアイデアは枯れてもまた湧くが、計測系が腐るとすべての採否が運任せに戻る
（改修指示書・締めの節と同旨）。守るべきものは変わらず計測系の信頼性であり、
それは八ヶ月前には存在しなかった。
